# Algorithms and Data Structures guide

Репозиторий содержит реализации базовых алгоритмов и структур данных на Python.

## Цель проекта

Проект создан в учебных целях — чтобы помочь новичкам разобраться во внутренней логике алгоритмов и научиться оценивать их сложность (Big O).

💬 Код подробно и по возможности понятно прокомментирован - чтобы легко разобраться, что происходит на каждом шаге
📈 Репозиторий будет постепенно пополняться разборами и решениями задач с LeetCode (интересных и не очень) и новыми алгоритмами
